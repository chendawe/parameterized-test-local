# LoRA 微调

## 宏观认识
公式拆解：对于一个线性层，原始前向传播是 h = W₀x。LoRA将其修改为：h = W₀x + BAx。

W₀ (d×k)：原始预训练权重，全程冻结（Frozen），不参与梯度更新。它是模型的通用知识库。

A (r×k) 和 B (d×r)：两个新引入的小矩阵，这是唯一需要训练的参数。

r (秩)：这是LoRA的核心超参数，且 r << min(d, k)。

参数量的暴力美学：
假设原始矩阵 W₀ 是 4096×4096，参数量约1677万。若设置 r=8，则新增矩阵 A (8×4096) 和 B (4096×8) 的总参数量仅为 4096×8 + 8×4096 = 65,536。这意味着，需要训练的参数直接减少了99%以上。

## 案例
视觉编码器：在Vision Transformer (ViT) 的Query、Key、Value投影层注入LoRA，帮助模型更关注特定领域的图像特征（比如医疗影像中的病灶区域）。

文本编码器/解码器：在Transformer的跨注意力模块添加LoRA，让模型学会如何将“看到的”与“要说的”精准对齐。

实战案例：在医疗视觉问答（Med-VQA）任务中，研究人员对 Idefics3-8B 等模型应用LoRA，仅用极小的训练成本，就在 VQA-RAD 数据集上达到了 86%-90% 的准确率，且能在仅有 15GB显存 的GPU上运行。这充分证明了LoRA在专业领域的强大落地能力。

## 参数
- 秩（r）
    - 起步指南：对于简单的任务（如格式化输出、风格模仿），r=4 或 8 足矣。对于复杂的垂直领域（如法律条文理解、医疗推理），可以从 r=16 开始尝试，复杂情况可调至 32 或 64
- 缩放因子（lora_alpha）
    - 经验值：通常设置为 r 的 2倍 或 4倍（例如 r=16，alpha=32），以保证训练的稳定性
- 目标模块（target_modules）
    - 标准配置：对于Transformer架构，注意力层中的查询（q_proj）和值（v_proj）投影是最佳切入点，直接影响模型对上下文的理解与特征提取。
    - 进阶配置：对于更复杂的任务，可以扩展到键（k_proj）、输出（o_proj）甚至前馈网络层（fc1, fc2）。在多模态模型中，还需指定跨注意力模块（cross_attn）。

- 学习率（Learning Rate）
    - 学习率（Learning Rate）：LoRA模块的学习率可以比全量微调时高出一个数量级，通常在 1e-4 到 5e-5 之间。因为要训练的参数极少，需要更大的步长来快速收敛。
    - 优化器：AdamW依然是主流选择。

## 变体

- QLoRA：显存的“终极节省术”。
    - 原理：在LoRA的基础上，先将基础模型（如LLaMA-65B）通过4-bit量化压缩，然后再挂载LoRA进行微调。
    - 效果：这使得在单张消费级显卡（如RTX 4090，24GB显存）上微调650亿参数的模型成为现实，极大地降低了技术门槛。

- AdaLoRA：让“好钢用在刀刃上”。
    - 原理：根据每个参数的重要性，动态地、自适应地分配“秩”。对于关键权重，分配更高的秩以精细调整；对于次要权重，则分配低秩甚至忽略。
    - 效果：在同等预算下，AdaLoRA能取得比标准LoRA更好的性能。例如，在医疗VQA任务中，Idefics3-8B模型使用AdaLoRA达到了90%的准确率，高于LoRA的86%。

- Text-to-LoRA：用“语言”生成“适配器”。
    - 原理：训练一个专门的神经网络，输入一段自然语言的任务描述（如“用莎士比亚风格写诗”），它就能直接生成对应的LoRA适配器权重，而无需再通过数据训练。
    - 意义：这预示着未来定制AI模型可能就像现在发指令一样简单，实现了“所想即所得”的模型适配。
